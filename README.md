# English with Ebru

A 2-week B1 English self-study course: daily lessons with audio, speaking practice with the microphone, auto-checked exercises, a grammar checker for writing, flashcards, mistakes, notes and progress.

- Live site: https://mghafary1.github.io/english-with-ebru/
- Progress is saved in the browser, and to the learner's account when logged in (Supabase, set in `config.js`).
- Writing is checked by [LanguageTool](https://languagetool.org) after the learner presses Submit.
- `vendor/supabase.js` is the Supabase JS client (MIT license), version 2.117.2.
